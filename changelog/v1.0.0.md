# v1.0.0

The first release of github-md-live-wiki: a free, MIT-licensed, content-agnostic wiki shell that
renders the markdown of any GitHub repository at view time.

## Reading

- Sidebar generated from the content tree, README-titled sections, GitHub-flavoured rendering
  with syntax highlighting, task lists, and GitHub-style heading anchors
- Full-text search over the version being viewed
- **On-device automatic translation** of the shown page (Español, Français, Deutsch, Italiano,
  Português, 日本語) via the browser's built-in translator — no keys, no server, code stays
  verbatim; offered only where the browser supports it
- Dark mode, mobile navigation, deep-linkable pages (`#/<version>/<path>`)

## Versions

- A selector offering **latest** (the default branch), every **release tag**, every **branch
  head**, and **any commit id** — all fetched live from GitHub, so merged content is visible
  immediately with no wiki deployment
- Links that leave the content tree open the file on GitHub at the matching version

## Shipping

- One public Docker image (`ghcr.io/jocaruser/github-md-live-wiki`), configured by env vars
  (`CONTENT_REPO`, `CONTENT_PATH`, `SITE_TITLE`, `APP_URL`, `DEFAULT_REF`)
- `serve` mode with an optional mounted `/content` directory for reading uncommitted edits;
  `export` mode for embedding the site into a consumer's GitHub Pages artifact
- Image tags `vX.Y.Z`, `vX` and `latest` — consumers pin the major
- This repository's own GitHub Pages hosts a live instance:
  <https://jocaruser.github.io/github-md-live-wiki/>
