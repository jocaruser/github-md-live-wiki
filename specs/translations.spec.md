# Automatic translation

Content is authored in English;
the wiki can translate the shown page for the reader,
on the reader's own device.

- Translation uses the browser's built-in translator.
  In browsers without one the language selector simply does not appear
  and everything else works unchanged.
- The top bar offers **Original** plus a fixed set of languages
  (Español, Français, Deutsch, Italiano, Português, 日本語).
- Choosing a language translates the rendered page in place:
  a subtle "Translating…" note while it runs,
  and the finished page reads in the chosen language.
- Code — fenced blocks, inline code, keyboard keys — stays verbatim:
  translating identifiers or commands would corrupt them.
- The choice persists across pages, versions and visits;
  every newly shown page arrives translated.
  Choosing **Original** restores the untranslated text immediately.
- Translated phrases are remembered for the session,
  so revisiting pages does not re-translate them.
- When the browser cannot translate into the chosen language
  (model unavailable, download refused),
  the page stays in English under a notice saying so.
