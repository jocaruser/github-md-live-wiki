# Search

The top bar offers full-text search over the version being viewed.

- The index covers the title and body text of every page
  of the current version — and only that version;
  switching versions re-indexes.
- Matches appear as the reader types:
  each shows the page title and its path,
  title matches ranked above body matches,
  at most twelve results.
- Choosing a match (click, or Enter for the first)
  opens the page at the current version and clears the box.
- Escape clears the box.
- Markdown syntax is not matched — words are.
