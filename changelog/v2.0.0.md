# v2.0.0

Live Wiki is now a general tool: open **any** GitHub repository, not a single configured one.

## Breaking

- The container takes **no content configuration**. The environment variables `CONTENT_REPO`,
  `CONTENT_PATH`, `SITE_TITLE`, `APP_URL` and `DEFAULT_REF` are gone, along with the mounted
  `/content` local mode. The image only serves the app (`serve`) or exports it (`export`); the
  reader chooses the repository at runtime. Pinning `:v1` will **not** upgrade to this — move to
  `:v2`.

## Choose a repository, share the view

- The app opens to a form: enter `owner/name` and a path, and read. A **Recent repositories** list
  and a **Close wiki** button make moving between repositories easy.
- The repository, path, version and page all live in the URL, so every link is shareable and
  reproducible — `#r=owner/name&p=docs&v=v1.2.0&f=guide/intro.md`. Absent version means the
  repository's default branch, resolved automatically.

## Also

- The version selector no longer has a "local" entry; it lists the opened repository's releases,
  branches, and any commit id.
- Own identity: documentation and ADRs describe Live Wiki on its own terms; engineering standards
  are recorded in ADR-0002 rather than inherited by reference.
- Everything else — live rendering, search, dark mode, on-device translation, 100% test coverage,
  offline e2e — carries over.
